## 🧩 About the Project  
This project showcases a dynamic photo gallery built with React. It fetches images from an API and allows users to save their favorite ones locally. Perfect for beginners exploring React hooks, component-based architecture, and client-side storage.

### Core Concepts Covered:  
- API fetching with `useEffect`  
- State management using `useState`  
- Saving and clearing favorites using `localStorage`  
- Conditional rendering and event handling  

---

## 🛠 Technologies Used  
- **React** – Component-based UI  
- **JavaScript (ES6+)** – Logic and interactivity  
- **CSS** – Styling the gallery layout  
- **LocalStorage** – Persisting user-selected favorites  

---

## ✨ Features  

📸 **Photo Gallery:**  
- Fetches images from an external API  
- Displays them in a responsive grid  

💾 **Save Favorites:**  
- Click on any image to save it to your favorites  
- Saved images persist via `localStorage`  

🗑️ **Clear Favorites:**  
- One-click button to clear all saved images  

⚛️ **React Hooks:**  
- `useState` for managing image and favorite states  
- `useEffect` for fetching data on component mount

## 🚀 Getting Started  

### Prerequisites  
- Node.js and npm installed  
- Basic understanding of React  

### Installation  
```bash
# Clone the repo  
git clone https://github.com/yourusername/gallery-project.git  

# Navigate into the folder  
cd gallery-project  

# Install dependencies  
npm install  

# Start the development server  
npm start  
```

Or just visit the [live demo](https://srinjay13.github.io/Gallery-Project/) in your browser!
